# Echo Protocol — EVOX 1.0

A prompt-built browser game for the EVOX 1.0 "Build a Game" challenge.

## Concept
Echo Protocol is a time-loop maze game. The player collects Memory Cores while every move is recorded. At intervals, an Echo appears and replays a previous route, turning the player's own history into a moving obstacle.

## Files
- index.html — game structure
- style.css — responsive visual design
- script.js — game mechanics

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
1. Create a GitHub repository.
2. Upload the three files.
3. Open Settings → Pages.
4. Select the main branch and root folder.
5. Save and wait for the GitHub Pages URL.

Alternative: drag the folder into Netlify Drop.

## Controls
WASD / Arrow keys on desktop. On-screen directional buttons on mobile.
